## 🛠️ TECHNICAL SPECIFICATIONS

### 💎 Graphics & Engineering
* **Rendering Engine:** HTML5 Canvas (2D) with automatic `devicePixelRatio` scaling for 4K clarity.
* **Visual Logic:** Additive color blending (`lighter`), CSS Glassmorphism, and `clip-path` geometry.
* **Architecture:** Pure Vanilla JavaScript (ES6+); zero external library dependencies for maximum speed.
* **UI/UX:** Responsive layouts with CRT Scanline filters and kinetic "Camera Shake" feedback.
